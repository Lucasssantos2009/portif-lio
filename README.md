## 📂 Projetos

O portfólio apresenta projetos práticos desenvolvidos para representar diferentes etapas da evolução técnica:

- 🐍 **Jogo da Cobrinha** — projeto web desenvolvido com HTML, CSS e JavaScript.
- 💻 **Portfólio Web** — interface para apresentação de conhecimentos, projetos e evolução técnica.
- 🤖 **Interface ChatGPT com API** — interface inspirada em chatbots modernos com integração com API de IA.
- ✊ **Pedra, Papel e Tesoura** — projeto em Python focado em lógica e interação.
- ❓ **Jogo de Adivinhação** — aplicação em Python para praticar lógica, condições e interação.
- 🎲 **Sorteador de Jogos Mega-Sena** — aplicação para geração de combinações aleatórias.
- 🕐 **Aplicativo Relógio** — aplicação desenvolvida em Java com foco em interface e componentes de interação.
- 💬 **Chatbot com Python + API** — experimento de conversação utilizando Python e APIs de modelos de IA.
- 📄 **Geração de Documentos** — automação para geração de documentos utilizando recursos do ChatGPT.
- ✨ **Projetos de IA Generativa** — explorações práticas envolvendo modelos generativos, prompting e aplicações de IA. :contentReference[oaicite:1]{index=1}
